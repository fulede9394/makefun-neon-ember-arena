Neon Ember Arena is an original top-down arena shooter: survive 10 waves of ember fiends, pick upgrades between waves, and clear wave 10 to win.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Move with WASD or arrow keys, aim with the mouse, shoot with click or Space. Press P to pause, M to mute, R to restart after a win or loss.
